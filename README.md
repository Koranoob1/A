# AMOLED Patches

An independent Morphe patch project for Proton Pass and Thunderbird on Android, developed through Vibe Coding.

## Proton Pass Pure AMOLED patch

Changes the dark palette's main background colors to AMOLED black (#000000), input surfaces to #0A0A0A, and input outlines to #242424, while preserving the Proton accent palette.

### Target

- App: Proton Pass F-Droid
- Package: proton.android.pass.fdroid
- Target version: 1.41.5

## Thunderbird Pure AMOLED patch

Changes dark Compose theme surfaces to AMOLED black (#000000), while preserving the light theme and accent colors.

### Target

- App: Thunderbird
- Package: net.thunderbird.android
- Target version: 25.0

## Compatibility

Target versions are pinned. Compatibility with later versions is not guaranteed.
